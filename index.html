Záloha a import

Databázi lze importovat z připraveného JSON nebo exportovat pro vlastní zálohu.

⇩

Import původní databáze

Vyber soubor hodiny_private_import.json připravený z tvého Excelu. Import proběhne pouze ve tvém zařízení a nepřepíše automaticky jiné dny bez potvrzení.

Zdrojový Excel obsahuje měsíce a dny, nikoliv rok; předvyplněn je rok 2026. Při importu běžné zálohy se rok nemění.

⇧

Export / záloha

Exportuj všechny záznamy, abys je mohl později obnovit nebo otevřít v Excelu. Doporučujeme zálohovat pravidelně.

JSON = plná obnova; CSV = pro Excel.

Jak funguje ukládání?

GitHub Pages hostuje pouze soubory aplikace. Všechny zápisy se ukládají lokálně do úložiště tohoto prohlížeče (localStorage). To znamená, že aplikace funguje i bez přihlášení, ale zápisy se nesynchronizují mezi telefonem a počítačem. Při vymazání dat prohlížeče se mohou ztratit – proto slouží export JSON. Původní data nikdy nepřidávej do veřejného GitHub repozitáře.
